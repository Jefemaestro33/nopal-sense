# Meeting Notes (public)

Summaries of chipathon-related meetings: weekly Zoom calls, tutorials, technical reviews. **Public** — keep content technical, no strategic/competitive intel here (eso va a Zafra-Agtech repo privado).

## Naming convention

`YYYY-MM-DD_topic.md`

Examples:
- `2026-05-08_kickoff.md`
- `2026-05-15_tool_installation.md`
- `2026-05-29_vipul_full_custom_analog.md`
- `2026-06-12_project_proposal_review.md`
- `2026-07-17_go_no_go_decision.md`

## Template

```markdown
# [Meeting Title] — YYYY-MM-DD

**Type**: Kickoff / Tutorial / Review / Mentor 1-on-1
**Attendees**: [names if relevant]
**Duration**: [HH:MM]
**Recording**: [URL if applicable]

## Topics covered
- Bullet 1
- Bullet 2

## Technical takeaways
- Insight 1
- Insight 2

## Decisions taken
- Decision 1 → see `docs/_decisions/ADR-NNN.md`

## Action items
- [ ] Action 1 (owner, deadline)
- [ ] Action 2

## Open questions / blockers
- Question 1

## References
- Slides: [URL]
- Related ADR: ADR-NNN
```

## What goes here vs Zafra-Agtech private

**Goes here (public)**:
- Technical summaries
- Tool/flow learnings
- Public chipathon decisions
- General Q&A

**Goes to Zafra-Agtech/docs/chipathon_notes/ (private)**:
- Strategic competitive analysis
- Mentor relationship dynamics
- Team formation negotiations
- Business implications of technical decisions
